가을이 깊어지면 **해가 확 짧아져요.** 여름 내내 잘 자라던 식물이 갑자기 웃자라거나 무늬가 흐려지는 것도 이때예요. 이럴 때 고민하게 되는 게 식물등이에요. 자리 조정으로 해결되는 경우도 많으니 [가을·겨울 자리 옮기기](/grow/가을겨울-식물-자리옮기기/)를 먼저 보셔도 좋아요.

## 먼저: 정말 필요한가요

다음에 해당하면 식물등을 고려할 만해요.

- 마디 사이가 **길게 늘어나며** 자람(웃자람)
- 무늬종의 **무늬가 점점 흐려짐**
- 새 잎이 이전보다 **눈에 띄게 작아짐**
- 잎이 한쪽 창 방향으로만 심하게 기울어짐
- 집에 **밝은 창가 자리가 아예 없음**

반대로 창가에서 잘 크고 있다면 굳이 필요하지 않아요. **자리를 옮기는 게 가장 싼 해결책** 이에요.

## 고를 때 보는 것

| 항목 | 기준 |
| --- | --- |
| 용도 | 식물용으로 나온 제품인지(일반 조명은 광량이 부족한 경우가 많음) |
| 광량 | 가까이 대지 않아도 충분한지 |
| 색감 | 흰빛 계열은 인테리어와 잘 어울리고, 붉은·보라 계열은 식물 색이 이상하게 보여요 |
| 설치 방식 | 클립형·스탠드형·레일형 중 내 공간에 맞는 것 |
| 타이머 | 내장 타이머나 별도 콘센트 타이머 |
| 발열 | 잎에 가까이 둘 거면 발열이 적은 쪽 |

> 사람 눈에 밝아 보이는 것과 식물이 쓰는 빛은 달라요. **일반 전구를 더 켜는 방식은 효과가 제한적** 인 경우가 많아요.

## 거리와 시간

- **거리**: 제품 안내를 기준으로 하되, 잎이 타거나 색이 바래면 더 멀리
- **시간**: 하루 10~12시간 정도로 시작
- **밤에는 꺼 주기**: 식물도 어두운 시간이 필요해요
- **타이머 사용**: 매일 켜고 끄는 걸 잊지 않게 해 줘요

자연광이 조금 있는 자리라면 **보조로 짧게**, 창이 없는 방이면 **주 광원으로 길게** 쓰는 식으로 조절해요.

## 함께 달라지는 것들

식물등을 켜면 식물이 더 활발히 자라요. 그래서 **다른 관리도 같이 조정해야** 해요.

- **물주기**: 생장이 빨라지면 물 마르는 속도도 빨라져요 → [물주기 기본](/care/관엽식물-물주기-기본/)
- **습도**: 난방까지 겹치면 건조해져요 → [습도 관리](/grow/관엽식물-습도-관리/)
- **비료**: 겨울에도 활발히 자란다면 아주 옅게 고려 → [비료 주는 법](/care/관엽식물-비료-주는법/)
- **통풍**: 빛만 늘리고 공기가 정체되면 병충해가 오기 쉬워요

## 실패하기 쉬운 부분

**너무 가까이 대기**
빛이 강하면 잎이 타거나 색이 하얗게 바래요. 새 잎 상태를 보며 거리를 조절하세요.

**24시간 켜 두기**
더 빨리 자랄 것 같지만 식물에 무리가 가요. 밤은 꺼 주세요.

**빛만 채우고 나머지는 그대로**
빛이 늘면 물·양분 소모도 늘어요. 흙이 계속 젖어 있으면 오히려 과습이 와요.

**인테리어 조명으로 착각**
장식용 조명은 광량이 부족한 경우가 많아요. 식물용인지 확인하세요.

## 체크리스트

- [ ] 자리 옮기기로 해결되는지 먼저 확인
- [ ] 식물용 제품인지 확인
- [ ] 설치 방식이 내 공간에 맞는지
- [ ] 타이머로 10~12시간 설정
- [ ] 2~3주 뒤 새 잎 크기·마디 간격 관찰
- [ ] 물주기 주기 재점검

## 마무리

식물등은 **빛이 부족한 겨울을 버티게 해 주는 보조 수단** 이에요. 먼저 자리를 조정해 보고, 그래도 웃자람이 이어지면 도입해 보세요. 집마다 창 방향과 밝기가 달라 필요한 정도도 다르니, 내 환경에 맞춰 시간과 거리를 조절하시길 권해요.
