가을이 깊어지면 **해가 확 짧아져요.** 여름 내내 잘 자라던 식물이 갑자기 웃자라거나 무늬가 흐려지는 것도 이때예요. 이럴 때 고민하게 되는 게 식물등이에요. 다만 자리 조정만으로 해결되는 경우도 많으니, [가을·겨울 자리 옮기기](/grow/가을겨울-식물-자리옮기기/)를 먼저 보셔도 좋아요.

## 정말 필요한가요

다음에 해당하면 식물등을 고려할 만해요.

- 마디 사이가 **길게 늘어나며** 자람(웃자람)
- 무늬종의 **무늬가 점점 흐려짐**
- 새잎이 이전보다 **눈에 띄게 작아짐**
- 흙이 열흘 넘게 **젖어 있음** (빛이 부족하면 물도 덜 먹어요)
- 집에 **밝은 창가 자리가 아예 없음**

반대로 창가에서 잘 크고 있다면 굳이 필요하지 않아요. **자리를 옮기는 게 가장 싼 해결책** 이에요. 빛이 얼마나 부족한지는 스마트폰 조도계 앱으로 재 보면 감이 와요 → [실내 빛 이해](/care/실내-빛-광량-이해/)

## 고를 때 보는 것

| 항목 | 기준 |
| --- | --- |
| 용도 | 식물용인지. 일반 조명은 광량이 부족한 경우가 많음 |
| 색 | 흰빛 풀스펙트럼이 무난. 붉은·보라 빛은 방이 어색해지고 식물 상태를 보기 어려움 |
| 밝기 | 가까이 대지 않아도 충분히 밝은지 |
| 설치 | 클립형, 스탠드형, 선반 부착형, 전구형 중 공간에 맞는 것 |
| 타이머 | 내장 타이머 또는 콘센트 타이머 |
| 발열 | LED는 열이 적어 잎 가까이 두기 좋음 |

해외 원예 자료와 재배자들도 집에서 쓰기엔 **흰빛 풀스펙트럼 LED** 를 가장 실용적인 선택으로 꼽아요. 식물에 필요한 파란빛과 붉은빛이 고르게 들어 있으면서, 방 안에서 봐도 눈이 편하기 때문이에요.

> 사람 눈에 밝아 보이는 것과 식물이 쓰는 빛은 달라요. **일반 전구를 더 켜는 방식은 효과가 제한적** 이에요.

## 거리와 시간

| 설정 | 시작점 | 조절 |
| --- | --- | --- |
| 거리 | 잎에서 15~30cm | 잎이 바래거나 타면 멀리, 웃자라면 가까이 |
| 시간 | 하루 10~14시간 | 자연광이 있는 자리면 짧게, 창 없는 방이면 길게 |
| 밤 | 꺼 주기 | 식물도 어두운 시간이 필요해요 |

제품마다 밝기가 달라서 설명서의 권장 거리를 우선으로 보세요. 해외 재배자들이 공통으로 말하는 신호는 이거예요. **잎 가장자리가 타거나 하얗게 바래면 거리를 늘리고, 새잎이 여전히 작고 줄기가 길면 가까이 가져가요.**

타이머는 꼭 쓰는 걸 권해요. 매일 같은 시간에 켜고 끄는 게 식물에게도 좋고, 깜빡할 일도 없어요.

### 더 정확하게 알고 싶다면

해외 재배자들 사이에서는 하루 동안 식물이 받는 빛의 총량을 뜻하는 **DLI(일일 광적산량)** 라는 개념을 쓰기도 해요. 같은 밝기라도 오래 켜면 총량이 늘어나는 원리예요. 그래서 밝기가 약한 등이라면 **시간을 조금 늘려** 보완할 수 있어요. 다만 앞서 말한 대로 밤에는 쉬게 해 주세요.

## 식물등을 켜면 함께 바뀌는 것

식물등을 켜면 식물이 더 활발히 자라요. 그래서 **다른 관리도 같이 조정해야** 해요.

- **물**: 생장이 빨라지면 흙이 마르는 속도도 빨라져요. 겨울이라고 여름보다 물을 줄이던 습관을 다시 확인하세요 → [물주기 기본](/care/관엽식물-물주기-기본/)
- **습도**: 난방까지 겹치면 건조해져요 → [습도 관리](/grow/관엽식물-습도-관리/)
- **비료**: 겨울에도 새잎이 활발히 나온다면 아주 옅게 줄 수 있어요 → [비료 주는 법](/care/관엽식물-비료-주는법/)
- **통풍**: 빛만 늘리고 공기가 정체되면 병충해가 오기 쉬워요 → [통풍과 공기 순환](/care/실내식물-통풍-공기순환/)

## 흔한 실수

**너무 가까이 대기**
빛이 강하면 잎이 타거나 하얗게 바래요. 새잎 상태를 보며 거리를 조절하세요.

**24시간 켜 두기**
더 빨리 자랄 것 같지만 식물에 무리가 가요. 밤은 꺼 주세요.

**빛만 늘리고 나머지는 그대로**
빛이 늘면 물·양분 소모도 늘어요. 반대로 흙이 계속 젖어 있다면 빛이 아직 부족하다는 뜻일 수도 있어요.

**장식용 조명으로 착각**
분위기 조명은 광량이 부족한 경우가 많아요. 식물용인지 확인하세요.

**켠 첫날 결과를 기대하기**
효과는 **새로 나오는 잎** 에서 보여요. 2~3주는 지켜봐야 해요.

## 체크리스트

- [ ] 자리 옮기기로 해결되는지 먼저 확인
- [ ] 흰빛 풀스펙트럼 식물용 LED인지 확인
- [ ] 설치 방식이 내 공간에 맞는지
- [ ] 타이머로 10~14시간 설정
- [ ] 2~3주 뒤 새잎 크기와 마디 간격 관찰
- [ ] 물주기 주기 다시 확인

식물등은 **빛이 부족한 겨울을 버티게 해 주는 보조 수단** 이에요. 먼저 자리를 조정해 보고, 그래도 웃자람이 이어지면 들여 보세요. 집마다 창 방향과 밝기가 달라서 필요한 정도도 다르니, 새잎을 보며 시간과 거리를 맞춰 가세요.
