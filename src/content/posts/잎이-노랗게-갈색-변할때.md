잎이 노래지거나 갈색으로 변하면 덜컥 걱정되죠. 그런데 해외 식물 커뮤니티의 진단 질문들을 보면, 대부분은 **몇 가지 질문만으로 원인이 좁혀져요.** 어느 잎에서 시작됐는지, 흙은 어떤 상태인지, 모양은 어떤지 순서대로 보세요.

## 첫 번째 질문: 흙은 어떤 상태인가요

잎만 보면 과습과 물 부족이 정말 비슷해 보여요. **흙을 먼저 만져 보는 게** 가장 확실한 단서예요.

- 흙이 **축축한데** 잎이 노랗게 무르며 처짐 → **과습** 가능성이 커요
- 흙이 **바싹 말랐고** 잎이 갈색으로 바삭함 → **물 부족**

나무젓가락을 흙 깊이 꽂아 보면 속 상태까지 알 수 있어요. 방법은 [물주기 기본](/care/관엽식물-물주기-기본/)에 있어요.

## 두 번째 질문: 어느 잎에서 시작됐나요

| 시작 위치 | 먼저 의심할 것 |
| --- | --- |
| 아래쪽 오래된 잎 | 과습, 질소 부족, 자연스러운 노화 |
| 위쪽 새잎 | 철분 등 영양 문제, 뿌리 손상, 급격한 환경 변화 |
| 창 쪽 잎만 | 직사광선 화상 |
| 잎 끝과 가장자리만 | 습도 부족, 물 스트레스, 비료·물 속 성분 |
| 여기저기 반점 | 병충해, 곰팡이성 병 |

식물은 양분이 부족하면 **오래된 잎의 양분을 새잎으로 옮겨요.** 그래서 질소나 마그네슘이 부족하면 아래 잎부터 노래지고, 옮길 수 없는 철분 같은 성분이 부족하면 새잎부터 색이 빠져요.

## 세 번째 질문: 어떤 모양인가요

| 모양 | 흔한 원인 |
| --- | --- |
| 잎 전체가 고르게 연노랑 | 질소 부족, 빛 부족 |
| 잎맥은 초록, 사이만 노랑 | 마그네슘·철분 부족 |
| 노랗고 물컹, 아래 잎부터 떨어짐 | 과습, 뿌리 썩음 |
| 갈색으로 바삭, 잎 전체 | 물 부족 |
| 잎 끝만 갈색으로 마름 | 건조, 물 스트레스, 염류 |
| 하얗거나 갈색으로 탄 자국 | 직사광선 |
| 검게 물러짐, 하룻밤 사이 | 냉해 |
| 노란 테두리의 갈색 반점 | 곰팡이·세균성 병 |

## 원인별 대처

**과습**
가장 흔한 원인이에요. 물을 멈추고 흙을 말려요. 일주일이 지나도 흙이 안 마르거나 냄새가 나면 화분에서 빼서 **검고 물컹한 뿌리를 잘라내고** 새 흙에 옮겨요 → [분갈이 방법](/care/분갈이-방법-시기/)

**물 부족**
저면관수로 흙 전체를 충분히 적셔요. 오래 말라 딱딱해진 흙은 위에서 부으면 물이 겉돌아요.

**잎 끝만 마를 때**
- 습도부터 확인해요 → [습도 관리](/grow/관엽식물-습도-관리/)
- 비료를 꾸준히 줬다면 흙에 염류가 쌓였을 수 있어요. 맑은 물로 흘려 씻어내요 → [비료 주는 법](/care/관엽식물-비료-주는법/)
- **물 속 성분에 예민한 식물** 도 있어요. 해외 자료에서는 드라세나, 접란, 칼라데아, 스파티필럼이 수돗물 속 불소 등에 예민해 잎 끝이 갈색으로 타기 쉽다고 알려져 있어요. 물을 받아 두면 염소는 날아가지만 불소 같은 성분은 그대로라, 이런 식물은 정수된 물을 써 보는 것도 방법이에요.

**영양 부족**
분갈이한 지 오래됐고 아래 잎이 고르게 연해진다면 성장기에 옅은 비료를 시작해 보세요. 다만 과습이나 빛 부족이 아닌지 먼저 확인하는 게 순서예요.

**빛**
직사광 화상이면 창에서 떨어뜨리고, 빛 부족이면 더 밝은 곳으로 옮겨요 → [실내 빛 이해](/care/실내-빛-광량-이해/)

**병충해**
잎 뒷면에 점이나 거미줄이 있다면 벌레를 의심해요 → [병충해 대처](/care/관엽식물-병충해-대처/)

## 자연스러운 노화도 있어요

식물은 새잎을 내면서 **가장 오래된 아래 잎을 한두 장씩** 떨어뜨려요. 새잎이 건강하게 계속 나오고, 한 번에 한두 장만 노래진다면 정상이에요. 해외 커뮤니티에서도 "아래 잎 하나 노래졌다고 물주기를 바꿨다가 오히려 문제가 생겼다"는 경험담이 꽤 있어요. 한 장보다는 **흐름** 을 보세요.

## 상한 잎은 어떻게 할까

노랗거나 갈색이 된 부분은 다시 초록으로 돌아오지 않아요.

- 잎의 절반 이상이 노랗다면 **잎자루째 잘라내요.**
- 끝만 조금 탔다면 **잎 모양을 따라** 초록 부분을 살짝 남기고 다듬으면 자연스러워요.
- 다만 원인을 해결하지 않으면 새잎도 같은 일을 겪어요.

잎 색 변화는 **흙 상태 → 시작 위치 → 모양** 순서로 보면 대부분 원인이 보여요. 헷갈릴 땐 가장 흔한 원인인 과습부터 의심하고, 물을 줄여 흙을 말려 보세요.
